\# Calculadora Financeira



Projeto desenvolvido em Python para realizar cálculos de Matemática Financeira.



\## Funcionalidades atuais



\- Cálculo do Capital / Valor Presente (VP)

\- Cálculo do Montante / Valor Futuro (VF)

\- Cálculo de Juros

\- Cálculo da Taxa

\- Cálculo do Tempo

\- Conversão de taxas entre dia, mês e ano

\- Conversão de taxa de desconto comercial para taxa efetiva

\- Conversão de taxa efetiva para taxa de desconto comercial



\## Capitalização



Nesta primeira etapa, o projeto utiliza capitalização simples.



\## Convenções utilizadas



\- 1 mês = 30 dias

\- 1 ano = 360 dias



\## Tecnologias utilizadas



\- Python 3

\- Git

\- GitHub

Em desenvolvimento.



Novas funcionalidades serão adicionadas conforme o avanço da disciplina.
